A newspaper front page summing up the world news of Thursday 26 November 2026 in one image: the US unveils sweeping new tariffs on 14 economies, Ukraine strikes a Russian airbase, a deadly fuel-tanker fire in Cairo, Israeli judges urge dropping the top Netanyahu charges, North Korea expels a Swiss diplomat, Abu Dhabi peace talks end without a deal, the Macy's Thanksgiving parade is postponed by bad weather, and Duran Duran guitarist Andy Taylor dies at 65. Pure Python 3 standard library: the program draws the whole front page into a pixel buffer and hand-encodes the PNG, deterministically, with no network and nothing to install.

## Run it

```sh
python3 main.py
```

This writes `output/entry.png` (1024x1024, under 1 MiB). Set `MAKEFUN_OUTPUT_DIR` to choose another output directory.
